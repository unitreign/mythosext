# mythosext

Community extensions for [Mythos](https://github.com/unitreign/mythos), a web novel reader plugin for KOReader.

## Adding this repo to Mythos

1. Open KOReader and launch Mythos
2. Go to **Sources**
3. Tap **Add Repo** and enter `github.com/UnitReign/mythosext`
4. Tap **Refresh Index**
5. Install any extension from the list

## Available extensions

| Name | Site | Language |
|---|---|---|
| NovelFire | [novelfire.net](https://novelfire.net) | English |

## Writing an extension

Check the [docs](docs/) folder. A good place to start is [getting-started.md](docs/getting-started.md), then [api-reference.md](docs/api-reference.md) for the full method signatures.

The `extensions/novelfire.lua` file is a working reference you can read alongside the docs.
